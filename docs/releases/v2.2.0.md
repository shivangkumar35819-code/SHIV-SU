# v2.2.0

- Keep successful login saved across app restarts.
- Remove repeated foreground and 30-second authorization loading, preserving navigation and image-picker results.
- Add a separate owner-only Telegram bot for exact custom keys, random keys, paginated license status, revocation and device reset.
- Reject duplicate keys and preserve generated keys across delivery retries.

Package: `com.shivksu.next`. Launcher name remains Instagram Lite. The version name is 2.2.0 and the Android version code increases for in-place updates. Release APKs use the existing signing identity and unchanged matching SukiSU 4.2.1 backend; choose ARM64 for most modern devices or universal when needed.

Login is saved locally until app data is cleared or the app is reinstalled. Server revocation and device reset affect future verification; they cannot sign out an already activated offline app. Duration-based expiry is not enforced in this login flow. The administration bot is independent of the existing OTP bot. Telegram service responses could not be verified during deployment because Telegram API requests timed out.

The APK update does not flash a kernel or boot image. Device-specific boot/root behavior is not verified by these build checks.
